## 👋 About Me

I'm **Mina Medhat** (GitHub: **codetic061-art**), a developer focused on building modern web interfaces and turning ideas into usable digital products.

I enjoy working on:
- **Web development** — responsive pages, polished UI, and complete user journeys.
- **AI-powered products** — useful learning experiences, AI tools, and automation concepts.
- **Interactive experiences** — motion, scroll-based storytelling, and 3D-inspired interfaces.
- **Product details** — accessibility, clear content, sensible interactions, and the small details that make an interface feel finished.

I'm currently developing **AI Hub**, an AI-learning and tools experience, while continuing to experiment with creative web interfaces.

> I prefer building real projects, testing ideas, and improving them step by step.
